# Hi, I'm Thomas 👋

**Cloud & Edge Architect** · I build Kubernetes platforms that reach from multi-cluster cloud all the way down to fleets of IoT devices at the edge.

By day I design large-scale observability for connected device fleets.
By night I run a homelab that's slightly too serious, pull aircraft out of thin air with an SDR, and write games in Rust.

---

### ☸️ Kubernetes & Platform Engineering
- Multi-cluster fleet management — Rancher, EKS, many downstream clusters
- Custom **Kubernetes operators** and controllers to automate the boring parts
- Infrastructure as Code with **Terraform / OpenTofu** and **Terragrunt**
- Cloud-to-edge observability: getting telemetry from thousands of devices into something useful

### 📡 IoT & Edge
- Edge workloads on constrained hardware, where "just restart the pod" isn't always an option
- **ADS-B / Mode-S** — decoding 1090 MHz aircraft signals with software-defined radio ✈️

### 🏠 Homelab
My house is my staging environment.

- **Network:** UniFi Dream Machine SE, VLAN-segmented, IPv6 on fiber, WireGuard on-demand VPN
- **DNS:** AdGuard Home with DNS-over-HTTPS, local split-horizon resolution behind a reverse proxy
- **Compute:** Proxmox VE, with a 3-node **Talos Linux + Ceph** Kubernetes cluster on the drawing board
- **Power:** rack UPS with NUT for graceful shutdowns
- **Smart home:** Home Assistant as the brain — Zigbee2MQTT, Shelly, ESPHome BLE proxies, Matter/Thread, plus custom integrations, Lovelace cards and e-paper dashboards

### 🎮 Games
- C++ and **Rust/Bevy** — currently building a 4X strategy game
